# Coding-agentic-ai

## Anchor

The design, engineering, and operation of AI coding agents and
agentic systems. Covers agent architectures, prompt engineering
for agents, context management, skill systems, multi-agent
orchestration, tool use patterns, evaluation frameworks, and the
practical craft of building reliable AI-powered software
development tools. This domain is about HOW to build and operate
agents -- the engineering discipline, not the underlying AI models.

## Scope

**In:** agent architecture patterns, prompt engineering for agents,
context window management and compression, skill/plugin systems,
tool use and function calling, multi-agent coordination, agent
evaluation and benchmarking, agent memory and persistence,
sandboxing and security, human-in-the-loop patterns, agent
observability and debugging, coding agent workflows, context
engineering, harness design, progressive disclosure in agent
instructions, self-improving agent systems, agent protocol design.

**Out:** general AI/ML theory (technology), LLM architecture and
training (technology), AI ethics (ethics-philosophy), AI regulation
(law-regulation), philosophical questions about AI consciousness
(ethics-philosophy), specific coding languages or frameworks
(technology), general software engineering (technology).
