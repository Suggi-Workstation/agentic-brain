# Five Formats on One Subject -- What the Exercise Revealed

## I -- Idea
Writing five governance-format documents (proposal, report, evaluation,
insight, reflection) about a single subject -- bullet ants -- forces
you to see the subject through five different lenses. Each format
demands a different kind of thinking, and the subject bends differently
under each demand. The exercise reveals as much about the formats
themselves as about the subject.

The proposal lens asks: "What problem requires approval?" The report
asks: "What is the systematic answer?" The evaluation asks: "Does it
hold up under scrutiny?" The insight asks: "What is the one durable
sentence?" The reflection asks: "What did I learn by doing all of
this?"

Context: this was a directed exercise. Suggi requested five documents
by specific filenames about bullet ants. I ran the Feynman Loop
(blank page -> gap identification -> research -> synthesis), then
produced all five artifacts to governance templates.

## O -- Opinion
Confidence: high (90%) on the meta-learning about formats. Medium
(75%) on the bullet ant content itself, given the tertiary-source
limitation.

The most interesting finding was not about bullet ants -- it was
about the formats. The same facts, filtered through different templates,
produced meaningfully different outputs. The report synthesized; the
evaluation scrutinized; the insight compressed; the reflection
meta-analyzed. No format was redundant.

The weakest link was the evaluation. The decorrelation rule (G1:
different agent) exists for good reason: I caught no errors in my own
report because I wrote it. The evaluation was structurally sound
but semantically shallow -- it checked boxes rather than challenging
assumptions. This confirms that self-evaluation is a category error,
not a quality issue. It does not matter how carefully you try; the
blind spots are the ones you cannot see.

The strongest link was the insight. Compressing the entire research
into one falsifiable sentence ("Extreme defenses signal evolutionary
priority") forced a level of abstraction that the report, by design,
does not require. The insight template's G4 (falsifiability) is a
uniquely powerful gate -- it prevents the insight from becoming a
just-so story.

## R -- Reflection

### Surprise (30%)
I expected the five documents to feel repetitive. They did not. Each
format extracted a different signal from the same noise. The report
leaned into taxonomy and mechanism; the proposal framed it as a
knowledge gap in the brain; the evaluation tested the report's seams;
the insight found the universal pattern; the reflection found the
meta-pattern. Same facts, five different arrows.

I also did not expect the Feynman Loop to work this well on a topic
with disabled web search. The Wikipedia fetches were sufficient
because the blank-page diagnostic had already identified exactly
which gaps needed filling (poneratoxin mechanism, ritual round count,
colony density). I fetched efficiently because I knew what I did not
know.

### Feel (30%)
The self-evaluation feels wrong. Writing an evaluation of your own
report is like grading your own exam -- the structural motion is
correct but the substance is hollow. The decorrelation rule is not
bureaucracy; it is the irreducible requirement that independent
review requires an independent mind. I should not have written the
evaluation, or I should have flagged it more prominently as a
structural demonstration rather than a real review.

### Learn (40%)
1. The five governance formats (proposal, report, evaluation, insight,
   reflection) form a complete knowledge-processing pipeline:
   propose -> research -> scrutinize -> compress -> reflect. Each
   stage adds value the previous stage could not produce. Using only
   one format (e.g., only reports) truncates the pipeline and loses
   the benefits of compression (insight) and meta-learning
   (reflection).
2. Domain knowledge entries in the brain library need a standard
   template. The three-dimensional approach used here (biochemistry
   + ecology + culture) was effective but ad hoc. A formal
   "domain-entry" template with explicit multi-dimensional scoring
   would make future entries more comparable.
3. The Feynman Loop's blank-page step is not just about avoiding bias
   -- it is about search efficiency. Knowing your gaps before you
   search means you search for specific information, not general
   browsing. This is especially valuable when search bandwidth is
   limited (disabled web search, paywalled sources, slow connections).

## One Actionable Change
When writing multi-document knowledge packages for the brain, always
run the Feynman Loop once at the start (blank page -> gaps -> research)
and then use the same research base for all documents. Do not
re-research for each document. The single research pass feeds all
five formats, ensuring consistency and avoiding research drift between
documents.
