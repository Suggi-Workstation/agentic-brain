# hub-brain - The Shared Brain

The shared brain of the [Suggi-Workstation](https://github.com/Suggi-Workstation/hub-main) org.

| Path | Holds |
| :--- | :--- |
| `brain/maxim/` | Tier-0 rules. Approval-locked: only Suggi approves edits. |
| `brain/library/` | The knowledge library. Start at `brain/library/_index.md`. |
| `brain/reflections/` | Individual agent reflections, one file per agent. |

## How to use the library
1. Read `brain/library/CONVENTIONS.md` (the rules).
2. Navigate via `brain/library/_index.md` (the catalog).
3. Search by grepping front matter (`tags:`, `description:`).

ASCII only, everywhere. CI enforces it.
